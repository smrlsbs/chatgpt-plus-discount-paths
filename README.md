## 折扣之外的真实成本

优惠码能省十几块，售后规则没看清可能亏掉整单。官方商品页明示的规则是这样的：

**账号类商品自购买日起 3 天售后期**，质量问题免费更换；邮箱类同样 3 天；**充值类到账后不售后**；卡密类因为可囤货，没有固定售后期。虚拟商品一经发货，除账密问题外不支持退款。

还有一条最容易被忽略：**超过 3 小时未核实的账号问题，平台可能不受理售后**。拿到账号第一件事就是登录验证，别等到第二天想起来再试。这一条比任何折扣码都值钱。

分品类还有各自的硬限制：

Gmail 的发货格式是“邮箱账号----密码----辅助邮箱”。辅助邮箱是恢复邮箱，本身没有密码，平台也不提供它的登录信息；身份验证时如果选错方式导致验证不了，不在售后范围内。所售谷歌账号**不能用于充值消费，不能用于登录游戏**，只能用于游戏下载。养号上，固定设备加稳定 IP 是底线，到手先开两步验证再改密码，首登 7 天内别大量收发邮件，同一 IP 同时登录的 Gmail 不超过 3 个。
